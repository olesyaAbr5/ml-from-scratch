# Линейная регрессия: прибыль автосервиса

Учебный проект: линейная регрессия одной переменной, реализованная с нуля (без готовых ML-библиотек для самого обучения модели)

## Задача

По числу автомобилей в городе (в тысячах) предсказать месячную прибыль автосервиса (СТО).

## Структура репозитория

- `main.ipynb` — основной ноутбук: загрузка данных, обучение модели, визуализация и оценка качества.
- `linear_regression.py` — функция стоимости и градиентный спуск, реализованные тремя независимыми способами (циклом, поэлементно через numpy, полностью в матрично-векторной форме) для взаимной проверки, плюс вспомогательные функции для визуализации.
- `predict.ipynb` — небольшой демонстрационный ноутбук: загружает обученные веса из `Theta.txt` и предсказывает прибыль по числу автомобилей, введённому пользователем.
- `data.txt` — обучающие данные (число автомобилей, прибыль).
- `Theta.txt` — сохранённые веса обученной модели.

## Метод

Модель обучается тремя независимыми способами (цикл / поэлементные операции numpy / матрично-векторная форма), после чего результаты сверяются друг с другом — это способ самопроверки корректности реализации градиентного спуска.

## Результаты

- J(θ) на обучающей выборке: 2.7488
- J(θ) на тестовой выборке: 5.3268
