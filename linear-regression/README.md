# Линейная регрессия: прибыль автосервиса

Линейная регрессия одной переменной с нуля на numpy: прогноз прибыли автосервиса по числу автомобилей в городе. Градиентный спуск реализован тремя способами (цикл, поэлементно в numpy, в матричной форме), результаты сверяются друг с другом.

- `main.ipynb` — обучение, графики, оценка качества
- `linear_regression.py` — функция стоимости и градиентный спуск
- `predict.ipynb` — прогноз по сохранённым весам

Результат: J(θ) = 2.75 на обучающей выборке, 5.33 на тестовой.
