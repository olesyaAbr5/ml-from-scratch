# Персептрон и Adaline

Персептрон и Adaline с нуля на numpy для бинарной классификации видов ирисов (датасет Iris).

- `perceptron_classificator.ipynb` — персептрон на 4 признаках и предсказание для нового цветка
- `adaline.ipynb` — Adaline с полным градиентным спуском: влияние learning rate и стандартизации

Результат: accuracy 100% на setosa vs versicolor, 94% на versicolor vs virginica.
