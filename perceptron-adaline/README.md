# Персептрон и Adaline на numpy

Реализация двух первых линейных классификаторов — персептрона Розенблатта и Adaline — без scikit-learn, только на numpy. 
## Данные

[Iris](https://archive.ics.uci.edu/dataset/53/iris) — 150 цветков трёх видов (setosa, versicolor, virginica), 4 признака: длина и ширина чашелистика и лепестка.


## Как запустить

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r ../requirements.txt
jupyter notebook
```

## Стек

Python, numpy, pandas, matplotlib, Jupyter
