# Логистическая регрессия: неисправность двигателя

Логистическая регрессия с нуля на numpy: вероятность неисправности двигателя по вибрации и неравномерности вращения. Градиент логлосса выведен вручную и записан в матричной форме, градиентный спуск идёт на стандартизованных признаках.

- `functions.py` — сигмоида, логлосс, шаг градиентного спуска, разделяющая граница, прогноз
- `ex1.py` — обучение при разных learning rate, разделяющая прямая, прогноз для нового двигателя, модель с нелинейным признаком x1·x2

Результат: логлосс 0.2035 у линейной модели и 0.0787 с признаком x1·x2. Запуск из папки: `python ex1.py`.
