# Персептрон: правило Хебба

Персептрон со ступенчатой функцией активации с нуля на numpy, обученный по правилу Хебба разделять два множества точек на плоскости.

- `functions.py` — ступенчатая функция, обучение по эпохам до первой эпохи без ошибок, графики точек и разделяющей прямой
- `main.py` — обучение с таблицей всех шагов, итоговые веса и разделяющая прямая
