# Линейная регрессия нескольких переменных

Линейная регрессия с двумя признаками, реализованная с нуля на numpy: градиентный спуск и аналитическое решение (нормальное уравнение).

## Задача

По двум признакам — скорости оборота и количеству передач — предсказать целевую величину. Данные: `ex1data2.txt` (205 объектов, столбцы: признак 1, признак 2, целевая переменная).

## Что сделано

`functions.py`:
- `featureNormalize` — стандартизация признаков: (x − μ) / σ;
- `computeCostMulti` — функция потерь J(θ) = 1/(2m) · Σ (Xθ − y)²;
- `gradientDescentMulti` — один шаг градиентного спуска в матричной форме;
- `normalEqn` — аналитическое решение θ = (XᵀX)⁻¹Xᵀy.

`ex1_multi.ipynb`:
- сравнение сходимости градиентного спуска при разных learning rate (α = 0.01, 0.03, 0.1, 0.3);
- сравнение градиентного спуска с аналитическим решением;
- предсказание для нового объекта.

## Результаты

Градиентный спуск (на стандартизованных признаках) и нормальное уравнение (на исходных) дают одинаковые прогнозы — совпадение до 6 знаков после запятой. Это проверка того, что градиентный спуск реализован верно.
