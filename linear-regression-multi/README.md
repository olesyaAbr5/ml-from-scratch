# Линейная регрессия нескольких переменных

Линейная регрессия с двумя признаками с нуля на numpy. Веса найдены двумя способами — градиентным спуском на стандартизованных признаках и аналитически (нормальное уравнение); прогнозы совпадают до 6 знаков, что подтверждает корректность градиентного спуска.

- `functions.py` — стандартизация, функция потерь, шаг градиентного спуска, нормальное уравнение
- `ex1_multi.ipynb` — сходимость при разных learning rate (0.01–0.3) и сравнение двух решений
